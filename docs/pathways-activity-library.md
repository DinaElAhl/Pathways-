# Pathways classroom activity library

Route: /activities. Free starter collection of 12 activities in maths, science, English, Arabic and cross-subject practice. These are authored classroom examples, not comprehensive curriculum coverage or standardised assessments.

Filters combine age, subject, suggested duration, purpose and keyword. Any-subject templates also appear within a selected subject. Each activity includes materials, directions, support and challenge adaptations and a teacher guide. Quizzes, ordering and sorting check answers locally, show corrections and wait for a teacher/learner retry. Discussion and optional brain breaks have no fabricated score. Printing includes student prompts and the teacher guide; print preview can be saved as PDF.

Activities are accessible without an account. Favourites are stored on this browser only; failed storage shows a recovery message. Permalinks select an activity on the same website. No learner name, response upload, membership entitlement or third-party activity embed is added.

Checks: node --test tests/classroom-activities.test.mjs; npm run build; isolated browser checks cover mobile fit, corrections, ordering, sorting, prompts, persistence, age filtering and print isolation.
